# Assets

The `assets` directory stores persistent numerical and graphical outputs from the scientific workflow. Refined and trusted analyses remain parallel so the effect of trusted-stage treatment is directly auditable.

| Directory | Purpose |
| --- | --- |
| `figures_analysis_refined/` | Stage-03 analytical figures from `data/refined/` |
| `figures_analysis_trusted/` | Stage-03 analytical figures from `data/trusted/` |
| `tables_analysis_refined/` | refined analytical and Moura–Ribeiro evidence tables |
| `tables_analysis_trusted/` | trusted analytical and Moura–Ribeiro evidence tables |
| `figures_paper/` | 300 dpi publication figures generated by Stage 05 |
| `tables_paper/` | five canonical publication tables generated by Stage 05 |

## Stage-03 analytical assets

The standard analytical table schema is identical for refined and trusted layers:

- `statistics_annual.csv`;
- `geometric_bins.csv`;
- `lorenz.csv`;
- `gompertz_annual.csv`;
- `pareto_annual.csv`;
- `gompertz_pareto_curves.csv`.

The Moura Jr.–Ribeiro reproduction component adds, for both layers:

- `moura_ribeiro_bootstrap_annual.csv`: bootstrap uncertainty diagnostics;
- `moura_ribeiro_reproduction_annual.csv`: annual quantities required to reproduce the 2009 tables and fit tests;
- `moura_ribeiro_evidence_annual.csv`: long-form evidence comparing current estimates with the published 2009 values.

The evidence table records the layer, test, estimator, parameter, estimate, standard error, fit metric, criterion, support status, published value, absolute and relative differences, and one-standard-error agreement when the paper reports an uncertainty.

Trusted-stage validation also produces `trusted_distribution_tests_annual.csv` and `trusted_trim_audit_annual.csv`.

## Publication assets

`src/stage_05_publication.py` is the canonical publication entry point. It consumes persisted Stage-03 results; no bootstrap or likelihood estimation is performed in Stage 05. Publication figures are written directly by the Stage-05 figure routines.

The canonical paper tables are:

- `table_01_gompertz_annual.csv`;
- `table_02_pareto_annual.csv`;
- `table_03_economic_inequality_annual.csv`;
- `table_04_metadata.csv`;
- `table_05_moura_ribeiro_evidence.csv`.

Table 01 separates the current fixed-`A` model from the free-intercept Gompertz diagnostic used to reproduce the 2009 methodology. Table 02 reports Fisher, likelihood-width and bootstrap uncertainty diagnostics for the direct Pareto MLE. Table 05 combines refined and trusted reproduction evidence in one paper-facing table.
