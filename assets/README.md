# Assets

The `assets` directory stores persistent numerical and graphical outputs generated by the scientific workflow. These files are derived products for analysis, validation, and manuscript preparation; record-level datasets and archival metadata remain under `data/`.

| Directory | Purpose | Stage |
| --- | --- | ---: |
| `figures_analysis_refined/` | analytical figures from the refined baseline | 03 |
| `figures_analysis_trusted/` | analytical figures from the trusted benchmark | 03 |
| `tables_analysis_refined/` | canonical refined analytical tables and data dictionary | 03 |
| `tables_analysis_trusted/` | canonical trusted analytical tables and data dictionary | 03 |
| `tables_validation/` | audit and quality-control tables for refined → trusted construction | 02 |
| `figures_paper/` | publication-ready figures | 05 |
| `tables_paper/` | publication-facing tables | 05 |

## Analytical assets

Stage 03 currently preserves parallel refined and trusted outputs so that sensitivity to trusted-layer construction can be inspected without changing the downstream statistical model. The two analytical table directories therefore have identical file sets and column schemas.

Each contains:

- `statistics_annual.csv`: annual descriptive and inequality summaries;
- `geometric_bins.csv`: geometric-bin and empirical-CCDF representation;
- `gompertz_annual.csv`: annual Gompertz estimates and diagnostics;
- `pareto_annual.csv`: annual Pareto estimates, support information and uncertainty diagnostics;
- `gompertz_pareto_curves.csv`: persisted combined-model curves;
- `lorenz.csv`: empirical Lorenz-curve coordinates;
- `metadata.csv`: table- and column-level data dictionary.

The corresponding figure directories contain analytical views generated from these products, including annual distributions, descriptive-statistic trajectories, inequality diagnostics, Lorenz geometry, CCDFs, and Gompertz–Pareto representations.

Unless explicitly stated otherwise, statistics derived from the released PNAD/PNAD Contínua records are record-weighted. The processed analytical datasets do not retain the complete original survey expansion weights and complex-design variables required for official population-design-weighted inference.

## Validation assets

The refined → trusted transformation has a separate validation layer:

- `trusted_trim_audit_annual.csv`: annual cutoff parameters, structural/statistical removal counts, distribution summaries and timing information;
- `trusted_distribution_tests_annual.csv`: deterministic structural and count invariants used to validate each trusted annual file.

These files document benchmark construction and are intentionally separate from Stage-03 analytical results. External IPEA and World Bank Gini series are used as consistency diagnostics and do not determine the trusted cutoffs.

## Publication assets

`src/stage_05_publication.py` is the canonical publication entry point. Stage 05 consumes persisted Stage-03 results and performs presentation only; parameter estimation, bootstrap resampling, likelihood-width calculations, regime-share estimation and fit diagnostics remain in Stage 03.

The canonical paper tables are:

- `table_01_gompertz_annual.csv`;
- `table_02_pareto_annual.csv`;
- `table_03_economic_inequality_annual.csv`;
- `table_04_metadata.csv`.

`table_04_metadata.csv` is the data dictionary for the publication-facing tables. Publication figures are generated at 300 dpi and are not authoritative substitutes for the underlying numerical tables.
