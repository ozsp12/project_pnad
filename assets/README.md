# Assets

The `assets` directory stores persistent numerical and graphical outputs generated by the scientific workflow. Refined and trusted analyses are kept in parallel directories so that the effect of the trusted-data treatment remains auditable. Analytical figures are SVG files, publication figures are 300 dpi PNG files, and numerical artifacts are CSV files.

| Directory | Purpose |
| --- | --- |
| `figures_analysis_refined/` | SVG analytical figures generated from `data/refined/` by Stage 03 |
| `figures_analysis_trusted/` | SVG analytical figures generated from `data/trusted/` by Stage 03 |
| `tables_analysis_refined/` | Numerical analytical artifacts generated from `data/refined/` |
| `tables_analysis_trusted/` | Trusted-stage audits and analytical artifacts generated from `data/trusted/` |
| `figures_paper/` | 300 dpi PNG publication figures generated by Stage 05 and `paper_figures.py` |
| `tables_paper/` | Four canonical publication tables generated by `paper_tables.py` |
| `figures_synthetic/` | Historical directory retained from the former standalone synthetic experiment |
| `tables_synthetic/` | Historical synthetic CSV outputs; no current `src` module regenerates them |

## Stage-03 analytical assets

The refined and trusted analysis directories are intentionally symmetric. Stage 03 applies the same analytical procedure to both layers, with geometric income grids using ratio `r = 1.10`.

| Analysis | Refined asset | Trusted asset |
| --- | --- | --- |
| Histograms | `refined_analysis_histograms.svg` | `trusted_analysis_histograms.svg` |
| Mean and median | `refined_analysis_income_mean_median.svg` | `trusted_analysis_income_mean_median.svg` |
| CCDF log-log | `refined_analysis_ccdf_loglog.svg` | `trusted_analysis_ccdf_loglog.svg` |
| Gompertz transform | `refined_analysis_ccdf_lnln.svg` | `trusted_analysis_ccdf_lnln.svg` |
| Lorenz geometry | `refined_analysis_lorenz_geometry.svg` | `trusted_analysis_lorenz_geometry.svg` |
| Top-income shares | `refined_analysis_top_income_shares.svg` | `trusted_analysis_top_income_shares.svg` |
| Mean/median and top shares | `refined_analysis_top_income_shares_mean_median.svg` | `trusted_analysis_top_income_shares_mean_median.svg` |
| Inequality indices | `refined_analysis_inequality_indices.svg` | `trusted_analysis_inequality_indices.svg` |
| Inequality indices 2×2 | `refined_analysis_inequality_indices_2x2.svg` | `trusted_analysis_inequality_indices_2x2.svg` |
| Gini validation | `refined_analysis_gini_validation.svg` | `trusted_analysis_gini_validation.svg` |
| Gompertz regime fits | `refined_analysis_regime_fits_gompertz_ccdf_empirical.svg` | `trusted_analysis_regime_fits_gompertz_ccdf_empirical.svg` |
| Pareto regime fits | `refined_analysis_regime_fits_pareto_ccdf_empirical.svg` | `trusted_analysis_regime_fits_pareto_ccdf_empirical.svg` |

The Gompertz figures report the final fixed-normalization model with $A=\ln[\ln(100)]$ and fitted $B$. A free-intercept regression is used only as a diagnostic to locate $x_{G,\max}$. Pareto figures retain both least-squares and direct-MLE estimates after the transition $x_t$ has been determined.

Stage-03 table filenames are identical in the refined and trusted directories; the directory itself identifies the data layer. One-row-per-year tables use the `_annual` suffix.

The canonical tables are:

- `statistics_annual.csv`;
- `geometric_bins.csv`;
- `lorenz.csv`;
- `gompertz_annual.csv`;
- `pareto_annual.csv`;
- `gompertz_pareto_curves.csv`.

`statistics_annual.csv` contains the PNAD inequality statistics together with the IPEA/World Bank Gini reference values and differences. Histogram and descriptive CCDF datasets are reconstructed directly from the Parquet inputs for plotting and are not persisted as separate CSV tables.

Trusted-stage validation additionally produces `trusted_distribution_tests_annual.csv` and `trusted_trim_audit_annual.csv`.

## Publication assets

`stage_05_moura_ribeiro.py` consumes trusted Stage-03 outputs and trusted Parquet observations to build the Moura Jr.–Ribeiro replication/extension through 2025. `paper_figures.py` finalizes publication figures and `paper_tables.py` consolidates exactly four canonical CSV tables:

- `table_01_gompertz_annual.csv`;
- `table_02_pareto_annual.csv`;
- `table_03_economic_inequality_annual.csv`;
- `table_04_metadata.csv`.

The publication workflow persists only the paper-facing assets in `figures_paper/` and `tables_paper/`.
