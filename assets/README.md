# Assets

<p align="justify">The <code>assets</code> directory stores reproducible evidence and computational artifacts generated by the scientific pipeline. Refined and trusted analyses are separated into parallel directories so that the effect of the trusted-data treatment can be inspected directly. Analytical figures are stored as SVG files, paper figures as 300 dpi PNG files, and numerical artifacts as CSV files.</p>

| Directory | Purpose |
| --- | --- |
| <code>figures_analysis_refined/</code> | SVG analytical evidence generated from <code>data/refined</code> |
| <code>figures_analysis_trusted/</code> | SVG analytical evidence generated from <code>data/trusted</code> |
| <code>tables_analysis_refined/</code> | Numerical analytical artifacts generated from <code>data/refined</code> |
| <code>tables_analysis_trusted/</code> | Trusted-stage audits and numerical analytical artifacts generated from <code>data/trusted</code> |
| <code>figures_synthetic/</code> | Reserved for figures from the standalone synthetic LS–MLE experiment |
| <code>tables_synthetic/</code> | CSV outputs generated by <code>src/synthetic.py</code> |
| <code>figures_paper/</code> | 300 dpi PNG publication figures generated by <code>src/stage_05_moura_ribeiro.py</code> and finalized by <code>src/paper_figures.py</code> |
| <code>tables_paper/</code> | Publication tables and manifest generated by <code>src/stage_05_moura_ribeiro.py</code> |

<p align="justify">The refined and trusted analysis directories are intentionally symmetric. Stage 03 uses the same analytical procedure for both layers; only the input dataset, output directory and filename prefix change. Geometric analysis grids use the Moura–Ribeiro ratio <code>r = 1.10</code>. When annual observations are unavailable, temporal plots may use interpolation for visualization only; underlying CSV values are not interpolated.</p>

### Trusted-stage audit tables

| CSV asset | Description |
| --- | --- |
| <code>trusted_distribution_tests_annual.csv</code> | Annual structural and numerical tests used to validate the refined → trusted transformation. |

<p align="justify">Tables with exactly one consolidated record per survey year use the <code>_annual</code> suffix. Tables containing multiple coordinates, bins or fitted points per year do not. ## Moura–Ribeiro paper assets

<p align="justify"><code>src/stage_05_moura_ribeiro.py</code> is implemented and generates the publication-specific replication and extension of Moura Jr. and Ribeiro (2009) over the available 1978–2025 trusted PNAD series. It reuses stage-03 outputs rather than recomputing the regime methodology. Multi-year figures are paginated in 3-column × 4-row grids with at most 12 panels. They use a 7.0 × 9.5 inch full-page LaTeX proportion and are stored only as 300 dpi PNG files; SVG and PDF copies are not maintained or regenerated.</p>

The publication tables include:

- <code>moura_ribeiro_2009_table_01_currency_mean_income_1978_2025.csv</code>;
- <code>moura_ribeiro_2009_table_02_gompertz_parameters_1978_2025.csv</code>;
- <code>moura_ribeiro_2009_table_03_pareto_parameters_1978_2025.csv</code>;
- <code>moura_ribeiro_2009_table_04_income_shares_gini_1978_2025.csv</code>;
- <code>moura_ribeiro_2009_exponential_fit_diagnostics_1978_2025.csv</code>;
- <code>moura_ribeiro_2009_figure_15_gdp_growth_1978_2025.csv</code>;
- <code>moura_ribeiro_2009_replication_manifest.csv</code>.

<p align="justify">The replication manifest maps the four original tables and fifteen original figure families to their current CSV/PNG assets. Fig. 15 uses the persisted World Bank/World Development Indicators series in <code>data/auxiliary/gdp_growth_brazil_1978_2025.csv</code>, indicator <code>NY.GDP.MKTP.KD.ZG</code>. Stage 05 reads this local snapshot and performs no World Bank request during execution.</p>
