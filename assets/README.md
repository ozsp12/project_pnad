# Assets

The `assets` directory stores persistent numerical and graphical outputs from the scientific workflow. Refined and trusted analyses remain parallel so that the effect of benchmark construction can be compared directly without changing the downstream analytical schema.

| Directory | Purpose |
| --- | --- |
| `figures_analysis_refined/` | Stage-03 analytical figures from the refined baseline |
| `figures_analysis_trusted/` | Stage-03 analytical figures from the trusted benchmark |
| `tables_analysis_refined/` | canonical Stage-03 baseline tables and metadata |
| `tables_analysis_trusted/` | canonical Stage-03 benchmark tables and metadata |
| `tables_validation/` | audit and quality-control tables for the refined → trusted transformation |
| `figures_paper/` | 300 dpi publication figures generated by Stage 05 |
| `tables_paper/` | four canonical publication tables generated by Stage 05 |

## Stage-03 analytical assets

The analytical table layout is intentionally identical for refined and trusted. Each directory contains the same six scientific CSVs:

- `statistics_annual.csv`;
- `geometric_bins.csv`;
- `gompertz_annual.csv`;
- `pareto_annual.csv`;
- `gompertz_pareto_curves.csv`;
- `lorenz.csv`.

Each directory also contains `metadata.csv`. This data dictionary documents the purpose of each table and gives a scientific definition, unit/scale, and source for every column.

Moura Jr.–Ribeiro reproduction diagnostics are not stored in separate bootstrap or reproduction files. Their useful annual outputs are consolidated directly into `gompertz_annual.csv` and `pareto_annual.csv`, including free-intercept Gompertz diagnostics, bootstrap standard errors, Pareto likelihood-width uncertainty, exponential comparison diagnostics, and regime income shares.

The refined directory represents the analytical baseline; the trusted directory represents the benchmark. Their filenames and column schemas are required to remain identical.

## Validation assets

The refined → trusted transformation has its own audit layer under `tables_validation/`. These files describe benchmark construction rather than benchmark analytical results and therefore are intentionally excluded from `tables_analysis_trusted/`:

- `trusted_trim_audit_annual.csv`;
- `trusted_distribution_tests_annual.csv`.

## Publication assets

`src/stage_05_publication.py` is the canonical publication entry point. Stage 05 consumes persisted Stage-03 scientific results and performs presentation only; parameter estimation, bootstrap resampling, likelihood-width calculations, regime-share estimation, and fit diagnostics remain in Stage 03.

The canonical paper tables are:

- `table_01_gompertz_annual.csv`;
- `table_02_pareto_annual.csv`;
- `table_03_economic_inequality_annual.csv`;
- `table_04_metadata.csv`.

Table 01 separates the current fixed-`A` Gompertz model from the free-intercept diagnostic used for comparison with the 2009 methodology. Table 02 reports the Pareto least-squares and direct-MLE estimates and their uncertainty diagnostics. Table 03 consolidates annual economic and inequality quantities. Table 04 is the paper-table data dictionary.
